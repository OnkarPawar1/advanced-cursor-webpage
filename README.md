# Advanced Presenter FX AV Mixer

## Run locally

```bash
npm install
npm run dev
```

Open the localhost URL printed by Vite (normally http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

The presenter cursor, pen, highlighter, laser, trails, click bursts and auto-fading annotations are drawn into the recording canvas so they are included in exported WebM recordings.
